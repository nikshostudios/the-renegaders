One night. Fifty thousand products.

We had one night to build a shopping agent that could find one product inside a catalog of fifty thousand.

This is the exact system we built for TechJam, the conversation it handles, and what happened when we tested it across all two hundred released public sessions.

The customer gives us five words.

Screen · request and baseline

The customer says, “I need a wallet.” That is all we get. No colour, no material, no price.

The official starter found the target in twenty five out of two hundred released public sessions. Twelve and a half percent.

So finding wallets was not enough. The agent had to remember what the customer meant, ask for one useful detail, and use the answer.

3

Here is the build.

Screen · animated mechanism

First, build a fast index over the catalog.

From there, keep the useful words from earlier turns. Ask for the missing detail. Then rerank the same products when the customer answers.

A title match counts more than a loose mention in the description. Filler gets dropped.

And the same conversation gives the same result every time. There is no model call hiding behind it.

4

Now run the agent.

Screen · terminal

Run: python3 demo.py --top-k 3

Alright, here is where it becomes useful. The first message is: “I’m looking for wallets, but I’m still exploring.”

The matches are wallets, but the agent still needs a material and a colour. So I give it two words: leather, black.

And there we go. Black leather wallets move to the top.

I never said wallet again. The agent carried it forward from the first message.

5

One conversation became two hundred.

Screen · result

Everything you just saw was one conversation. So then we ran all two hundred released public sessions.

The starter found twenty five targets. This agent found one hundred and eighty seven.

Hit Rate at 10 reached 0.935. The technical score reached 0.808740. The target appeared after 2.945 turns on average.

We also tested changes that sounded clever and scored worse. We removed them.

6

The result, without the sales pitch.

Camera · face

Everything I just showed runs locally. Zero model tokens. Zero API cost. No network call.

Local timing changed between runs, from a twenty two millisecond median to forty six. That number depends on the machine and its load.

We have not seen the private set. What we can prove is that the complete public result reproduced exactly.

One vague request. Two added words. Fifty thousand products. And one hundred and eighty seven targets found.

That is the agent we built in one night.
